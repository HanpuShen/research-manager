# Demo memory

A small synthetic research project for trying Research Manager and for the README screenshots. All numbers and figures are synthetic. Paper records hold arXiv metadata only (no PDFs).

Try it: `RESEARCH_MEMORY_ROOT=examples/demo-memory npm run preview`, or point the extension's memory folder here. Rebuild with `npx tsx scripts/demo/build-demo-memory.ts` (needs Python with matplotlib and network access to arXiv).
